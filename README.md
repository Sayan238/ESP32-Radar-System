# 🚀 ESP32 Radar System

A professional radar system using ESP32, HC-SR04 ultrasonic sensor, and servo motor.

## 📌 Features

- Real-time radar scanning
- Ultrasonic obstacle detection
- Professional radar UI
- Servo motor rotation
- Live visualization using Processing IDE

---

## 🛠 Components Used

- ESP32 Dev Module
- HC-SR04 Ultrasonic Sensor
- MG90S Servo Motor
- Jumper Wires
- Breadboard

---

## 🔌 Wiring

| Component | ESP32 Pin |
|---|---|
| Servo Signal | GPIO 18 |
| Ultrasonic TRIG | GPIO 5 |
| Ultrasonic ECHO | GPIO 17 |

---

## 💻 Software Used

- Arduino IDE
- Processing IDE
